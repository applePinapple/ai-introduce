# 演讲素材

图片、截图、视频和参考模板放在此目录。引入外部素材时，记录出处和使用说明。

- [黑马程序员 AI 通识与 LangChain／Agent 课程视频](videos/bilibili/BV178w1z7EHQ/README.md)：演讲准备的参考素材，含来源、下载说明和分 P 索引。

当前演讲稿使用可编辑文字、原生形状和表格，并通过 `imagePath` 引用 `design/` 中的概念插画。`video-evidence/` 保存视频抽帧与核对记录，`research/` 保存资料核验结果；`redesign/` 保存 HTML 样稿所需的原稿提取清单、图片、字体及模板依据。
