## 演讲重构建议

建议 50 分钟按 6 分钟开场与历史、4 分钟神经网络直觉、17 分钟 LLM、18 分钟 Agent 应用、5 分钟落地与讨论配置。历史和神经网络作为理解前提，不等比例复述视频。

四段视频没有完整的 Agent 规划—工具—观察闭环教学。Agent 应用应明确作为**基于课程的延伸**，用已核验论文和官方技术文档支撑。退款助手、采购比价、代码修复可用作新增教学示例，但不得包装为真实客户案例或编造效果数字。

课程中的一些断言或数据不宜直接照搬：`Token=词`、统一的 `12288` 维和 `128K` 上下文、未公开确认的 GPT-4/GPT-5 参数/训练硬件、达到规模临界点便突然拥有智能、已跨入 AGI 门槛。正式幻灯片应采用准确限定，或删去未证实数字。
