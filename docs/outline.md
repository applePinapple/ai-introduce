## 视频提炼与扩展范围

四段指定视频总时长约 56 分 26 秒，内容涉及 AI 通识、神经网络、大语言模型与大模型应用。提炼依据是实际抽帧后的课件、图示和可见硬字幕，没有进行音频逐字转写；记录见 `assets/video-evidence/extraction-notes.json` 与帧清单。

保留的主要教学线索包括：神经网络识别手写数字、北京早餐的逐 Token 生成，以及语言模型和传统程序的分工。视频中的参数估计、统一上下文窗口、Token 等同于词及 AGI 判断不直接照搬。历史日期与技术结论以原始论文和官方资料限定表述。

四段视频没有完整讲授 Agent 的行动反馈闭环。第 22 页之后的系统定义、工具调用、状态、验证、权限与应用架构主要依据论文与官方工程资料扩展，并在对应页备注中引用。课程提炼与扩展范围在开场讲稿交代。

## 讲解与事实边界

- 一页聚焦一个问题，屏幕展示主线，细节、过渡语与例子解释放入备注。
- 规则程序、机器学习与神经网络不是严格替代的单一路线；达特茅斯提案日期为 1955 年，研究项目为 1956 年。
- Token 是模型使用的离散单位，未必等于一个词；上下文长度、具体能力与行为依模型和产品而变。
- 注意力和下一 Token 预测用于解释机制，不据此承诺回答必然正确或声称模型像人一样思考。
- RAG 是检索增强方法，可以嵌入固定工作流，也可以成为 Agent 使用的工具。
- Agent 采用本讲约定：模型结合反馈选择后续步骤与工具。所有示例均保留任务结束、失败处理与人工确认的位置。
- 订单、知识库、销售、代码与经营分析情景按教学示例或实施建议呈现，不当作已经发生的客户案例或已实现的收益。
- 客服研究等真实结果保留研究对象、指标和适用范围。效果不能直接外推到本团队，试点收益需扣除复核、模型与运行成本。
- 先用真实任务样本建立评价，再逐步扩大工具权限和任务范围。

## 资料与交付

`content/sources.json` 保存视频与外部原始来源，并记录 2026-10-13 的核验日期、支持范围及可用的视频时间段。每页 `sourceIds` 关联资料，完整记录进入 PPT 备注、Markdown 讲稿和离线可打印 HTML 讲稿。

当前排版使用暖白与深蓝交替、青绿色强调，以及表格、示例、过程、对比和大字重点页。封面插画是生成的概念视觉，不作为事实证据。

构建前检查内容与测试，构建后验证 PPTX 包结构和完整内容，再用实际演示软件逐页渲染检查。正式演讲时可按交流速度微调停顿，但修改页时长后应保持总计 3000 秒。
