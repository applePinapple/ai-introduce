# 已确认的 HTML 幻灯片风格

用户在 2026-10-13 确认本技能所附三页样例满意，并要求以后优先使用这套风格。默认直接应用，不再重新提供风格候选。此偏好只针对幻灯片；不影响网站、文档等其他任务。新的明确要求优先于此默认。

## 开始时

- 先看 [已确认三页总览](assets/approved-example/preview.png)，再读 [视觉与实现规则](references/design-system.md)。以确认过的成品为准，不只根据风格名称猜测。
- 在 `ai-describe` 项目中，复用 `src/slides/`、`content/decks/sample.json` 和当前构建/验证流程；内容正文与讲稿仍由 JSON 维护，不能只改生成目录。
- 在其他工作目录中，用 `python scripts/new-deck.py <目标目录>` 从本技能创建完整、离线可播放的副本，再按用户的主题改写。脚本不覆盖已有目录。也可直接读取附带 HTML 的组件、CSS、SVG 和播放代码。
- 默认交付 HTML，并保留相邻 `media/`；需要静态阅读时由浏览器导出 PDF 和 PNG。若用户明确要求 PPTX 等格式，遵循该格式，用同样的视觉系统适配，不擅自交付成 HTML。

## 制作约定

- 固定 1920×1080 设计画布，整体等比缩放；正文页采用 84/104/72 px 的上/左右/下边距。沿用确认样例的色值、字号、网格和组件。
- 采用原生 HTML/CSS、SVG、Flex 与少量 JavaScript。标题、正文、表格保持可编辑；技术图用本地图片或 SVG，不能将整页截图用作正文。
- 三页示例提供封面、闭环图和对照表的具体写法，不限制未来页数或版式种类。按内容需要扩展论文图、实验图、公式、时间线等组件，保持同一视觉系统。
- 蓝色对应信息/模型，橙色对应行动/输出，绿色对应状态/反馈。内容变换时维持语义一致；一个页面只解释一个主要问题。
- 保留方向键/空格、Home/End、数字、G 目录、F 全屏、C 页码、鼠标区域和 URL hash 的播放方式。
- 保留本地字体与授权；不要改成依赖远程字体或服务。背景网格使用不透明描边颜色渐变，避免 Chrome 导出 PDF 丢失透明遮罩。
- 样例内容是风格示范，不是新主题的通用事实依据。沿用事实时核查其原始来源；新数字、日期和产品能力需要核验。完整引用与详细解释放讲稿，教学示例明确标注。
- 仅制作当前授权内容；用户满意三页风格不表示授权改写完整演讲。不要复制参考作者署名，也不要复活已被用户弃用的其他模板。

## 验证与维护

在项目中运行 `npm run check`、`npm test`、`npm run build`、`npm run verify`。其他目录至少检查实际浏览器中的所有页面、媒体/字体加载、翻页与目录、文字越界、离线打开和 PDF 分页；逐页看导出图，不以脚本成功替代视觉复核。

本技能的 `assets/approved-example/deck.html` 和 `preview.png` 是用户确认的视觉基准。修改正文不需要更新基准；只有用户明确认可新的视觉方向后才更新技能基准。参考来源与适配记录见 [来源记录](references/provenance.json)。
