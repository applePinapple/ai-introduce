# 已确认的视觉与实现规则

以技能内 `assets/approved-example/deck.html` 与 `preview.png` 为基准。该版本在 skJack/-lip- 第21期 VLA 风格上完成字体、播放、打印兼容修正，已获得用户认可。

## 画布与字体

| 元素 | 设计基准（px） |
| --- | --- |
| 舞台 | 1920×1080，浏览器中心，`scale(min(innerWidth/1920,innerHeight/1080))` |
| 页面 | `section.slide`；普通模式只有 `.active` 显示；窄屏不重排 |
| 正文页边距 | 上84、左右104、下72 |
| 顶部眉题 | 等宽22，字距 `.14em`；左侧10px蓝点+章序，右侧英文主题 |
| 标题 | 60，字重600，行高1.2，上距16 |
| 同行副题 | 28，字重400，灰色，左距20 |
| 正文区域 | 顶距26，默认列间距36，Flex双栏或纵向分组 |
| 正文 | 说明/表格/步骤30，列表34，大字说明42 |
| 封面 | 左104、上150；标题150、行高1；副题44；底部300高图片带 |
| 页脚来源 | 左右104、底40，等宽20；详细解释移入讲稿 |

正文无衬线，标签/数字等宽，公式衬线。保留 PingFang SC / Hiragino Sans GB / Noto Sans CJK SC 优先顺序；附带 Noto Sans SC 与 JetBrains Mono 作为离线回退。Windows 中文等宽标签也明确回退到 Noto Sans SC / Microsoft YaHei，避免意外使用宋体。

允许按内容调整列宽、图像大小与间距，不靠缩小全局字号塞内容。三页是组件范例，未来页数取决于演讲目标。

## 色彩与组件

| 用途 | 色值 |
| --- | --- |
| 背景 / 卡片 / 正文 | `#EEF2F6` / `#FFFFFF` / `#0B1220` |
| 次要文字 / 边线 | `#5B6B7F` / `#D3DBE5` |
| 蓝 / 淡蓝 | `#2457F5` / `#E3EAFF` |
| 橙 / 淡橙 | `#FF6B1A` / `#FFE9DB` |
| 绿 / 淡绿 | `#1B9E77` / `#DDF3EC` |

蓝=信息/模型，橙=行动/输出，绿=状态/反馈。白卡片1px边线、12–14px圆角；图片框阴影 `0 8px 30px rgba(11,18,32,.06)`。步骤卡片padding18/24，左侧语义色边条8px。图片标签向上突出16px，19px等宽，黑底或语义色底。

表格为原生 `table`，仅横向分隔线，正文30、表头21左右；统计卡数值50、标签20，必须使用真实指标。公式44衬线。常用布局包括大图+说明、输入/圆形模型/输出、步骤链+表格、图片标注、时间线、公式+图解。按讲述问题选布局，不强制每页都堆卡片。

图片默认 `object-fit:contain`；照片与封面装饰图可 `cover`，不裁掉技术图的坐标轴或图例。封面图片 `display:block`，消除行内图片基线溢出。原作者的品牌不作为新演讲署名。

## 透视网格

- SVG视口1920×1080，消失点(960,330)。射线末端x从-1400到3300，每190一根，y=1080。
- 横线从y=370开始，初始步长8，每次乘1.32；线宽1，整体opacity .55，不拦截点击。
- 不透明描边渐变采用 `gradientUnits="userSpaceOnUse"`、y1=0、y2=1080：0和55%为 `#EEF2F6`，100%为 `#DCE3EB`。
- 底部色值等价于原 `#D3DBE5` 线条被35%背景色遮罩覆盖，避免透明SVG遮罩在Chrome PDF中合成失效。上半页安静，下半页渐显网格。
- 每页渐变与marker ID唯一，不复制原项目重复的 `id="fade"`。

## 播放与打印

HTML内联CSS/JS，媒体和字体从相邻 `media/` 读取，不引入幻灯片框架、远程字体、后台服务或模型API。用 `data-sec`、`data-title` 生成左上角目录。方向键、PageUp/Down、空格翻页，Home/End首尾，G目录、F全屏、C页码；连续数字延时500ms跳页；`#N` 与 `?nav=1` 定位。

鼠标左20%上一页、其余下一页，按钮/链接/视频独立响应。切入视频页时重置播放，切出暂停；按C或停留同页不重启视频。同名媒体应报错或唯一命名，不能静默覆盖。

备注放 `template[data-speaker-notes]` 或配套讲稿，保留完整引用和核验日期。页脚仅短来源，教学示例明确标注。

打印使用 `@page{size:1920px 1080px;margin:0}`，所有页面显示、取消舞台缩放、逐页分页、隐藏导航、保留背景。截图隐藏导航和提示。PDF/PNG是派生结果，HTML保持可编辑。字形边界略超行盒不等于裁切，应检查实际裁切祖先和画布边界。

## 验收

逐页查看浏览器和PDF渲染，检查换行、图片、表格、标注、字体和总览密度。验证1920×1080、1280×720与窄屏下等比完整显示，PDF页数等于幻灯片数；媒体/字体加载、脚本错误、导航、hash与离线播放均应通过。新主题事实需重新核验，不能照搬无关的示例引用。
